# KEBDA STREET
**From a Small Cart to Egypt's Street Food Empire.**

A mobile-friendly 3D Egyptian street-food game prototype built with React, TypeScript, Vite, Three.js, React Three Fiber and Zustand.

## Run
`npm install`
`npm run dev`

## Build
`npm run build`

## Prototype
- Stylized Egyptian street scene and interactive 3D kebda cart.
- Third-person camera follows movement buttons.
- First order handoff and simple cash/reputation counters.
- GitHub Actions build workflow.

## Planned next
Real cooking mechanics, customer AI/navigation, ingredient inventory, persistent saves, day/night cycle, sound, upgrades, employees and business expansion. The current order interaction is a prototype placeholder, not the final cooking system.
